# Launchpad Preview

a platform where crypto projects can list their project as prelaunch. to create hype.
discover upcoming projects.
list your project: site, x, dev x, launch date, logo, project description.

sign in with google
submit form page
home page / explorer page
project card view.

your goal is to build this to make it polished, beautiful and site should look like a site of a YC backed funded startup. avoid using grids, flashy colour. make it simple, minimal.
